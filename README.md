# Retail Sales Analysis Using SQL

## Project Overview

This project analyzes retail sales data using SQL. The goal is to explore customer behavior, sales performance, product categories, and transaction patterns through SQL queries.

The project covers data cleaning, data exploration, business analysis, aggregation, window functions, and reporting queries commonly used by Data Analysts.

---

## Dataset Information

The dataset contains retail transaction records with the following fields:

| Column Name     | Description                   |
| --------------- | ----------------------------- |
| transactions_id | Unique transaction identifier |
| sale_date       | Date of sale                  |
| sale_time       | Time of sale                  |
| customer_id     | Customer identifier           |
| gender          | Customer gender               |
| age             | Customer age                  |
| category        | Product category              |
| quantity        | Quantity purchased            |
| price_per_unit  | Price per unit                |
| cogs            | Cost of goods sold            |
| total_sale      | Total transaction amount      |

## Data Cleaning

Performed the following checks:

* Identified NULL values across all columns.
* Checked duplicate transaction IDs.
* Verified data integrity before analysis.

### Duplicate Check

```sql
SELECT transactions_id, COUNT(*)
FROM retail_sales
GROUP BY transactions_id
HAVING COUNT(*) > 1;
```

## Key SQL Concepts Used

### Aggregation

```sql
SELECT category,
       SUM(total_sale) AS net_sale
FROM retail_sales
GROUP BY category;
```

### Window Functions

```sql
RANK() OVER(
PARTITION BY year
ORDER BY avg_sale DESC
)
```

### Common Table Expressions (CTE)

```sql
WITH hourly_sale AS (
    ...
)
SELECT shift,
       COUNT(*)
FROM hourly_sale
GROUP BY shift;
```
